# フロントエンド

[English](README.md) | **日本語**

CinePost 映画マイクロブログプラットフォームの React + Vite フロントエンドです。

## セットアップ

```bash
cd frontend
npm install
npm run dev
```

アプリは `http://localhost:5173` で起動します。先にバックエンドを `http://localhost:3000` で起動しておく必要があります。

## ページ

| ルート | コンポーネント | 説明 |
|---|---|---|
| `/` | MovieSearch | すべての映画の閲覧・検索 |
| `/movie/:id` | MovieDetail | レビューを含む映画の詳細ページ |
| `/users` | UserSearch | ユーザーの発見・検索 |
| `/users/:id` | UserProfile | 投稿と統計情報を含む公開ユーザープロフィール |
| `/login` | Login | アカウント登録またはログイン |

## コンポーネント

| コンポーネント | 役割 |
|---|---|
| `App.jsx` + `TopNav` | ルーティング、認証状態、ナビゲーションバー |
| `Login` | アカウント登録・ログインフォーム |
| `MovieSearch` | 検索入力欄付きの映画一覧 |
| `MovieCard` | 映画 1 件の概要カード |
| `MovieDetail` | レビュー、「いいね」・返信の件数を含む映画の詳細ページ |
| `UserSearch` | 好みの共通度に基づくランキングによるユーザーの発見 |
| `UserProfile` | ユーザープロフィール：投稿、フォロワー数・フォロー数、フォローボタン |
| `Feed` | ログイン中のユーザー向けに投稿を新しい順に表示するフィード |

## 認証状態

ログインまたはアカウント登録を行うと、JWT トークンとユーザーオブジェクトが `localStorage` に保存されます。ページを再読み込みした際には認証状態が復元され、ログアウトすると両方の値が削除されます。
